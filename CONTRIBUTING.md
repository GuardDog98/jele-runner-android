# Contributing

Thanks for your interest in contributing! This is a small prototype project — contributions are welcome (bug fixes, improvements, assets).

How to contribute

1. Fork the repository.
2. Create a new branch for your change: `git checkout -b my-feature`.
3. Make changes and run the project locally to verify.
4. Commit and push: `git commit -am "Describe your change" && git push origin my-feature`.
5. Open a Pull Request describing the change and why it's useful.

Guidelines

- Keep changes small and focused.
- For art/asset contributions: include license/source information.
- For code: prefer clear, commented changes and avoid breaking the build.

Reporting issues

Use the Issues tab to report bugs or request features. Provide steps to reproduce and device/Android version.
