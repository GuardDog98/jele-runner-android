ABOUT

Playable prototype

Jele Runner is a lightweight mobile prototype focused on the fun loop: move across lanes, collect coins, avoid danger, and unlock visual upgrades. It was designed to feel fast, simple, and satisfying on Android devices.

🏃

Runner gameplay

Simple lane switching and jump mechanics for quick arcade sessions.

🪙

Coin economy

Collect coins, build a score, and use them in the skin shop.

🎨

Skins

Unlock new colorways and keep the prototype feeling fresh.

🔊

Audio + haptics

Short sounds and vibration make the experience more alive.

RUN IT

Launch locally

git clone https://github.com/GuardDog98/jele-runner-android.git
cd jele-runner-android
open in Android Studio

Run it on an Android emulator or a device with API 29+.
