ANDROID GAME PROTOTYPE

Run, dodge, collect, and win the lane.

Jele Runner is a compact 3D runner prototype made in Kotlin with OpenGL ES. Collect coins, buy skins, avoid obstacles, and survive as long as you can.

ABOUT

Playable prototype

This project was built as a small Android game prototype with a 3D runner feel. The game focuses on smooth lane switching, coin pickups, obstacle avoidance, and a simple skin shop driven by in-game coins.

🏃

Runner gameplay

Lane-based movement with simple jump and dodge mechanics.

🪙

Coin system

Collect coins for score and unlock your next skin.

🎨

Skin shop

Use earned coins to buy new character colors and styles.

🔊

Audio + feedback

Short game sounds and vibration improve the arcade feel.

RUN IT

How to launch locally

git clone https://github.com/GuardDog98/jele-runner-android.git
cd jele-runner-android
open in Android Studio

Then run the project on an Android emulator or a device with API 29+.
